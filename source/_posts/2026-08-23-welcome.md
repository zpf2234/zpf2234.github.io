这个博客总算搭起来了。

我用 **Hexo + Anzhiyu** 写它。文章放在 `source/_posts/`，写完提交到 GitHub，Actions 负责生成页面并发布到 GitHub Pages。

这里主要记前端、AI 和各种工具的使用过程。看番时想到的东西也会放一点，但不会专门把它做成资讯站。

## 现在用什么

- Hexo 7
- Anzhiyu 主题
- 自定义 CSS / JavaScript
- GitHub Pages
- GitHub Actions

## 怎么写文章

文章统一放在 `source/_posts/`。本地看效果：

```bash
npm run server
```

确认没问题后提交到 GitHub，Actions 会自动生成 `public/` 并发布网站。
